# Code of Conduct

We welcome feedback, bug reports, and suggestions for improving this project.

If you find a bug or have an idea, please open a GitHub Issue and describe it clearly and respectfully. When reporting a bug, try to include:

- What happened
- What you expected to happen
- Steps to reproduce the issue
- Screenshots or error messages, if useful

Please keep all discussions professional, constructive, and respectful.  
Comments that are offensive, disrespectful, or unrelated to the project may be removed.

Thank you !
